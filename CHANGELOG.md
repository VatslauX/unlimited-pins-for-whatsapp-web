# Release notes

## 0.2.0 — 2026-11-12
- **Smaller chat rows**: the extension's toolbar icon opens a settings panel where you can show the chat list in Medium or Compact rows instead of WhatsApp's Original size. Open WhatsApp Web tabs change at once, and the choice stays after a reload.

## 0.1.1 — 2026-11-12
- No changes to how the extension works. New versions are now published to the Chrome Web Store automatically.

## 0.1.0 — 2026-11-11
- **Pin more than 3 chats**: WhatsApp's own **Pin chat** menu item and keyboard shortcut pin a 4th chat and more. Extra pins show at the top of the chat list with WhatsApp's pin icon and stay after a reload.
- The first 3 pins are normal WhatsApp pins and sync to your phone. Pins past 3 are kept only in this browser and never sent to WhatsApp.
- Pins and unpins show up in every open WhatsApp Web tab.
